## 🔍 Overview & Design Principles

The objective of this assignment is to design and simulate a fully functional **4-bit IC-level Arithmetic Logic Unit (ALU)** adhering to strict hardware constraints:
- **IC-Level Implementation:** Built exclusively using standardized 74xx-series digital logic integrated circuits (ICs) rather than high-level behavioral Logisim blocks.
- **SSI/MSI Partitioning:**
  - The parallel adder is driven by standard 74xx MSI adders (`74283`).
  - The combinational logic network feeding operand $B$ and carry signals into the parallel adder is constructed **entirely from SSI gates** (`7404`, `7408`, `7432`, `7486`).
  - Operation multiplexing is performed using standard multiplexers (`74157`).
- **Component Minimization:** Optimized gate-level expressions using Karnaugh maps (K-maps) to minimize IC package count.

## 🔌 Input / Output Interface

### Inputs
| Signal | Bit Width | Description |
| :--- | :---: | :--- |
| `a3, a2, a1, a0` | 4 bits | Operand $A$ (`A[3:0]`) |
| `b3, b2, b1, b0` | 4 bits | Operand $B$ (`B[3:0]`) |
| `cs2, cs1, cs0` | 3 bits | Control Select Lines determining the active ALU operation |

### Outputs
| Signal | Bit Width | Display Element | Description |
| :--- | :---: | :---: | :--- |
| `s3, s2, s1, s0` | 4 bits | Output LEDs | Final ALU 4-bit computation result |
| `C` | 1 bit | Status LED | Carry Flag (indicates unsigned carry-out from arithmetic) |
| `S` | 1 bit | Status LED | Sign Flag (indicates negative result in 2's complement, $S = \text{MSB}$) |
| `V` | 1 bit | Status LED | Overflow Flag (detects signed arithmetic overflow) |
| `Z` | 1 bit | Status LED | Zero Flag (asserted high when result is `0000`) |

## ⚙️ Functional Specifications

The ALU operates across arithmetic and logical modes controlled by the 3 control signals `cs2, cs1, cs0`.

### Operation Mode Table

| `cs2` | `cs1` | `cs0` | Operation Class | Function Performed | Circuit / Stage |
| :---: | :---: | :---: | :--- | :--- | :--- |
| `0` | `0` | `0` | Arithmetic | **Add with Carry** ($A + B + C_{in}$) | 74283 Adder |
| `0` | `1` | `1` | Arithmetic | **Decrement $A$** ($A - 1$) | 74283 Adder |
| `1` | `0` | `0` | Arithmetic | **Add** ($A + B$) | 74283 Adder |
| `1` | `1` | `1` | Arithmetic | **Subtract with Borrow** ($A - B - 1$) | 74283 Adder |
| `X` | `0` | `1` | Logical | **Bitwise XOR** ($A \oplus B$) | 7486 XOR IC |
| `X` | `1` | `0` | Logical | **Bitwise OR** ($A + B$) | 7432 OR IC |

*(Note: In addition, bitwise NOT / AND operations and transfer modes are handled through the gate combinational array and multiplexer routing).*

### Status Flag Logic

The status register flags ($C, S, V, Z$) are updated following conventional computer architecture conventions:

1. **Carry Flag ($C$):**
   - Reflects the carry-out generated by the `74283` 4-bit binary adder during arithmetic operations.
   - Cleared (`0`) during logical operations.
2. **Sign Flag ($S$):**
   - Equal to the most significant bit of the result (`s3`).
   - Reflects negative values in 2's complement representation.
3. **Overflow Flag ($V$):**
   - Detects signed 2's complement overflow: $V = C_{in\_msb} \oplus C_{out\_msb}$.
   - Evaluated using: $V = (A_3 \cdot B_3 \cdot \overline{S_3}) + (\overline{A_3} \cdot \overline{B_3} \cdot S_3)$.
   - Cleared (`0`) for logical operations.
4. **Zero Flag ($Z$):**
   - Asserted high (`1`) when all result bits are zero: $Z = \overline{s_3 + s_2 + s_1 + s_0} = \overline{s_3} \cdot \overline{s_2} \cdot \overline{s_1} \cdot \overline{s_0}$.

## 🧮 IC Chip Manifest & Hierarchy

The circuit [`ALU.circ`](./ALU.circ) uses standard 74-series TTL ICs:

| IC Part Number | IC Type / Description | Quantity | Role in Circuit |
| :--- | :--- | :---: | :--- |
| **7404** | Hex Inverters (NOT Gates) | 2 | Complementing inputs, control signals, and condition generation |
| **7408** | Quad 2-Input AND Gates | 3 | Combinational input conditioning feeding the adder stage |
| **7432** | Quad 2-Input OR Gates | 2 | Bitwise OR logic operations & input mixing |
| **7486** | Quad 2-Input XOR Gates | 2 | Bitwise XOR logic operations, complementation & overflow calculation |
| **74157** | Quad 2-to-1 Data Selectors / Multiplexers | 2 | Selecting between arithmetic and logical output buses |
| **74283** | 4-Bit Binary Full Adder with Fast Carry | 1 | Core parallel arithmetic addition/subtraction engine |

## 🚀 How to Simulate in Logisim

1. **Open the Circuit:**
   Launch Logisim or Logisim-evolution and open [`ALU.circ`](./ALU.circ):
   ```bash
   logisim Assignment-1-ALU/ALU.circ
   ```
2. **Set Inputs:**
   - Use the **Poke Tool** (`Ctrl+1` / `Cmd+1`) to toggle inputs `a0-a3`, `b0-b3`, and the control select pins `cs0-cs2`.
3. **Observe Results:**
   - Check the **Result LEDs** (`s3, s2, s1, s0`) for the 4-bit output.
   - Inspect the **Status Register LEDs** (`C, S, V, Z`) to verify flag generation.
